# Satoshi

Satoshi by Indian Type Foundry, distributed through Fontshare.

Source: https://www.fontshare.com/fonts/satoshi
CSS source: https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700&display=swap

The application self-hosts the 400, 500 and 700 WOFF2 files to avoid a font request to a third party during use.

## Baloo 2

Baloo 2 by Ek Type, licensed under the SIL Open Font License 1.1.
Source: https://github.com/EkType/Baloo2

The restored local Latin variable WOFF2 supplies rounded display headings (weights 400-800). Body copy and monetary figures use Satoshi. Both are served locally.
